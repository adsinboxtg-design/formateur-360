# Méthodologie

Décrire ici, dans tes mots, comment tu construis un cours : comment tu découpes, comment tu choisis le fil rouge, comment tu évalues.
Les agents s'appuient sur ces fichiers ; plus ils sont précis, moins le résultat est générique.

- `chaine-de-production.md` : les étapes de conception et qui fait quoi
- `formateur-360.md` : le parcours complet (vendre, concevoir, faire valider)
