# Confidentialité de Formateur 360 pour ChatGPT

Cette page couvre la version ChatGPT de Formateur 360. Elle comporte des instructions, des modèles et des scripts de travail. Le paquet ne contient ni serveur externe de Formateur 360 ni connexion à un compte Formateur 360. Les documents et instructions que vous fournissez dans ChatGPT suivent les règles et réglages de votre compte ChatGPT. Consultez la [politique de confidentialité d’OpenAI](https://openai.com/policies/eu-privacy-policy/) et les réglages de votre espace.

Certaines étapes peuvent utiliser des outils disponibles dans votre session. Par exemple, le dépôt d’un support sur Google Drive dépend de votre connexion et de l’action que vous demandez. Si vous exécutez vous-même un script Apps Script exporté, le traitement correspondant a lieu dans votre compte Google. Consultez les règles applicables au service utilisé.

Pour les essais, privilégiez des pièces anonymisées et évitez de joindre des données identifiantes sur vos apprenants.

Pour poser une question générale sur la confidentialité, utilisez le [canal d’assistance](support.md). Le suivi GitHub est public. N’y joignez aucun document personnel et n’y publiez aucune donnée permettant d’identifier quelqu’un.

Cette notice décrit le fonctionnement du paquet distribué. Elle ne fixe pas de délai de conservation pour des traitements distincts de ce paquet.
